# NegArtesanales
## Descripción del proyecto
Plataforma web para promover negocios locales.
## Características principales
*Nota: Este sistema se encuentra en fase de desarrollo.*
El sistema cuenta con un **diseño web responsivo** y conexión a **base de datos MySQL**.
## Procedimiento de instalación
1. Instalar y ejecutar XAMPP.
2. Iniciar los servicios de Apache y MySQL.
3. Clonar el repositorio en la carpeta htdocs.
4. Importar la base de datos.
