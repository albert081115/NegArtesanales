# 🏺 NegArtesanales

## 📝 Descripción del Proyecto
**NegArtesanales** es una plataforma web innovadora diseñada específicamente para la difusión, promoción y gestión de negocios artesanales. Este espacio digital busca conectar a los artesanos locales con clientes potenciales, ofreciendo un escaparate virtual que preserva el valor cultural y fomenta el comercio justo.

###  Objetivo General
Desarrollar un entorno web intuitivo y accesible que permita digitalizar los catálogos de artesanías, automatizar la administración interna del negocio y ofrecer una experiencia de navegación óptima para los usuarios interesados en piezas únicas.

---

##  Tecnologías Utilizadas
El proyecto se ha construido utilizando una arquitectura robusta y estándar para el desarrollo web:
* **Frontend:** HTML5, CSS3 (con estilos personalizados `estilos.css`) y Bootstrap para el diseño responsivo.
* **Backend:** PHP para la lógica del servidor y gestión de sesiones (`index.php`, `admin.php`).
* **Base de Datos:** MySQL para el almacenamiento seguro de productos, categorías y usuarios.
* **Control de Versiones:** Git y GitHub para la colaboración y el despliegue.

---

## Características del Proyecto
* **Presentación de productos:** Catálogo dinámico con imágenes de alta calidad (ej. vasijas de barro negro) y fichas técnicas detalladas.
* **Diseño web interactivo:** Interfaz limpia, moderna y fácil de utilizar para cualquier tipo de usuario.
* **Base de datos optimizada:** Conexión persistente mediante un script centralizado (`conexion.php`) para garantizar consultas rápidas.
* **Panel de Administración:** Módulo privado (`admin.php`) desde el cual se pueden agregar, editar o eliminar productos del catálogo.

---

## Importancia del Proyecto
*A través de NegArtesanales, se reduce la brecha digital que suelen enfrentar los productores tradicionales. Esta herramienta no solo sirve como un catálogo, sino como un motor de desarrollo económico local que facilita que más personas conozcan la riqueza de nuestras artesanías de manera inmediata.*

---

## Procedimiento para Ejecutar el Proyecto
Para desplegar y probar **NegArtesanales** en un entorno de desarrollo local, sigue rigurosamente estos pasos:

1. Instalar la suite de desarrollo **XAMPP** en tu equipo.
2. Iniciar los servicios correspondientes de **Apache** y **MySQL** desde el panel de control de XAMPP.
3. Mover o clonar la carpeta completa del proyecto dentro del directorio raíz `htdocs` de XAMPP.
4. Importar o crear la base de datos necesaria en **phpMyAdmin** (MySQL).
5. Configurar los parámetros de acceso a la base de datos en el archivo `conexion.php`.
6. Abrir tu navegador web preferido (Chrome, Firefox, Edge, etc.).
7. Ingresar a la dirección local `http://localhost/NegArtesanales/` para comenzar a interactuar con la plataforma.
