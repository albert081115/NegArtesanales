
# Negartesanales

## Descripción del proyecto

Negartesanales es una plataforma web diseñada para dar a conocer productos de negocios artesanales, facilitando la presentación de sus productos y permitiendo que los usuarios conozcan las diferentes opciones disponibles.

### Objetivo

Desarrollar una plataforma web que permita mostrar productos artesanales y ofrecer un espacio digital para promover los negocios locales.

## Tecnologías utilizadas

El proyecto utiliza diferentes herramientas y tecnologías para su desarrollo.

## Características del proyecto

El proyecto **Negartesanales** busca apoyar la difusión de los negocios artesanales mediante una plataforma web.

Entre sus principales características se encuentran:

- **Presentación de productos:** permite mostrar los diferentes productos artesanales.
- **Diseño web:** cuenta con una interfaz sencilla y organizada.
- **Base de datos:** utiliza MySQL para almacenar la información.

## Importancia del proyecto

*Negartesanales busca ofrecer una alternativa digital para promover el trabajo de los artesanos y facilitar que más personas conozcan sus productos.*

## Procedimiento para ejecutar el proyecto

Para utilizar Negartesanales en un entorno local, se deben seguir los siguientes pasos:

1. Instalar XAMPP en el equipo.
2. Iniciar los servicios de Apache y MySQL.
3. Colocar la carpeta del proyecto dentro de `htdocs`.
4. Crear la base de datos en MySQL.
5. Configurar la conexión en el archivo `conexion.php`.
6. Abrir el navegador web.
7. Ingresar a `http://localhost/NegArtesanales/` para visualizar el proyecto.
